# 开发提示词（可直接整段复制给 Claude / Codex / 豆包）

> 用法：先粘【提示词】，再把 `docs/PRD.md` 一起给它。生成后按【验收清单】逐条点，不合格就贴回问题让它改。
> 这套提示词的写法就是工作坊第 12 页的骨架：产品目标 + 页面结构 + 交互功能 + 视觉要求 + 验收标准。

---

## 提示词

```
你是一名做过消费级移动端产品的资深前端工程师。请用原生 HTML/CSS/JS（不引入框架、不需要构建）做一个可以直接在手机浏览器打开的校园免费资源聚合应用，名字叫「白捡」。

【产品目标】
校园里每天都有人免费送出东西（食堂临期、活动剩料、毕业闲置、讲座空位），但信息散在群里，5 分钟就被刷走。这个产品把这些免费供给收拢到一个地方，用「倒计时 + 真实库存 + 3 公里内」让人来得及去拿。
用户是大学生，单手操作，网络一般，会在食堂排队时打开。

【页面结构】
1. 首页：顶部位置（可切校区）+ 搜索；深橄榄色数据卡（今天还有多少份免费 / 多少份 30 分钟内过期 / 本月已省多少钱）；五个分类 chip（全部/吃的/好物/名额/资料/服务）；「手慢无」横滑卡（45 分钟内过期）；「离你最近」纵向列表。
2. 快过期：按剩余时间升序，每条显示大倒计时。
3. 发布：表单（这是什么 / 类型 / 在哪 / 多少份 / 多久内有效 15-30-60-180 分钟 / 说明），提交后回首页且新条目置顶。
4. 我的：省钱账单（累计省下多少钱、领取次数、减少浪费 kg）、我的领取记录（带 4 位领取码）、Pro 订阅入口。
5. 详情：从底部上滑的弹层，含大图区、标题、距离与步行时间、库存、倒计时进度条、说明、领取规则、发布者认证、多少人正在看、底部「立即领取」。
6. 底部 4 个 tab，中间是凸起的「＋」发布按钮。

【交互功能】
- 分类筛选即时生效；搜索按标题/地点/说明过滤。
- 点卡片打开详情弹层；点遮罩或 × 关闭。
- 点领取：库存 -1，生成 4 位领取码，按钮变「已领取 · XXXX」，卡片出现「已领取」标签，我的页面省钱金额同步增加。
- 发布后新条目排在首页第一位，并有一次入场强调动画。
- 数据存 localStorage，刷新不丢；如果所有条目都已过期，第二天自动补一批种子数据。
- 倒计时每秒更新；条目过期后变灰并显示「已结束」。
- 支持下拉刷新（提示「上新了一件」）。

【视觉要求】
奶油白背景 #F2EDE2，卡片 #FFFDF8，正文近黑 #1C1B18，主色低饱和橄榄绿 #6E7C52，紧迫色砖红 #C8552F。
圆角 18-26px，阴影极轻，字号小而克制（正文 12-14px，标题 20-26px），大量留白，像一本纸质小册子，不要蓝色科技渐变、不要玻璃拟态堆叠、不要 emoji 满屏。
移动端 390px 宽必须完美；桌面端左侧显示产品说明、右侧显示手机框。
所有内容用 emoji + 单色渐变作为配图，不依赖外部图片（离线也要能看）。

【动效要求】
列表入场做 9px 位移动画 + 34ms 错峰（不要用 opacity 从 0 开始，弱设备或截图环境下内容会不可见）；
弹层 translateY 上滑 + 遮罩淡入；领取成功有一次轻量粒子（canvas，60 个以内，1 秒内结束）；
数字滚动计数；按钮按下 scale(.97)；tab 切换内容淡入。
所有动效必须尊重 prefers-reduced-motion。

【技术要求】
单页应用，无构建、无依赖，index.html + styles.css + app.js + data.js；
PWA：manifest + service worker（网络优先、失败回缓存），可添加到主屏；
所有用户输入必须转义后再插入 DOM；
不使用 alert/confirm，用底部 toast。

【验收标准（必须逐条自测并给出结果）】
1. 首页显示 ≥12 条，hero 数字 = 所有在架条目的库存之和。
2. 点「吃的」，列表数量变化且只显示该分类。
3. 点卡片，弹层打开且标题与卡片一致。
4. 点领取，出现 4 位码，按钮变为已领取，返回「我的」能看到这条记录和增加的省钱金额。
5. 发布一条，回到首页它排在第一位。
6. 390×844 无横向滚动条，四个 tab 全部可点。
7. 刷新页面，领取记录和新发布内容还在。
8. 控制台无报错。
```

## 迭代提示词（第二、三轮用）

**修 bug 时给它现象，不要给它结论：**
```
在 390 宽的手机上点「发布」，提交后首页第一条不是我刚发的那条，而是剩余时间最短的那条。
我期望：我刚发布的排在第一位并高亮 2 秒。只改排序逻辑，不要动其他地方。
```

**加功能时给边界：**
```
加「开抢提醒」：详情页底部加一个铃铛按钮，点击后 30 分钟内该条目剩 5 分钟时，用浏览器的 Notification 提醒我。
限制：只允许提醒 3 个条目；用户没授权时降级成 toast 提示；不要申请后台推送权限。
```

**改视觉时给参照：**
```
现在的卡片信息太挤。改成：标题最多两行、距离和库存合并成一行小字、倒计时单独放右下角并与库存对齐。
保持现有配色和圆角，不要引入新颜色。
```

## 验收清单（AI 说完成之后，自己点一遍）

- [ ] 分类切三次，数字都在变
- [ ] 打开详情，关掉，再打开另一条，标题不串
- [ ] 领取两次同一条，第二次提示「已经领过」
- [ ] 把一个条目的库存点到 0，按钮变「已领完」且不能领
- [ ] 发布空标题，被拦下
- [ ] 手机横屏、平板宽度，不塌
- [ ] 断网后刷新，页面还能打开（service worker 生效）
- [ ] 控制台 0 报错
